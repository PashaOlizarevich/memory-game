# Интерфейс и дизайн

Источники: [DESIGN](../../docs/DESIGN.md), [Architecture](../../docs/Architecture.md), [AGENTS](../../AGENTS.md).

- Сохраняй тему Star Wars: космос, светящиеся акценты, восемь разных силуэтов, единая рубашка. Токены/тексты/размеры из DESIGN; не добавляй режимы/звук без задачи. Генерация картинок необязательна; источники ресурсов фиксируй в README при необходимости.
- Весь DOM через document.createElement, текст textContent, дерево DOM-методами; все запреты HTML-строк/системных диалогов/библиотек из AGENTS действуют для окон тоже.
- Render отображает snapshot, CSS не определяет правила. Обновляй карточки/счётчики; колоду пересоздавай только при смене раунда. Анимация не управляет таймером.
- Grid 4 × 4 от 320 px без горизонтального скролла. Проверяй 320/375/768/1440; даты, кнопки, изображения не обрезаются.
- Настоящие button, focus, Enter/Space; закрытый образ скрыт визуально и из доступности. Имя сообщает номер/статус; fallback образа виден лишь после открытия. Декор не озвучивается; aria-live не раскрывает скрытые образы. Найденные пары различимы не только цветом.
- Одна собственная modal-оболочка: DOM-содержимое, role dialog/aria-modal/aria-labelledby, background inert, сохранение/восстановление overflow, focus внутрь, удержание Tab/Shift+Tab.
- Закрытие кнопкой/Escape/фоном только при target === overlay, не содержимым. Возврат focus к триггеру, резерв и автоматическая победа — «Новая игра» хедера.
- Обновление поля таймером не пересоздаёт окно и не меняет focus. Новая игра из окна/хедера — общий handler modal.close(), game.restart(). Обработчики не накапливаются.
- Reduced motion убирает декор, сохраняет игровые 1000 мс. При storage memory показывай сообщение о возможной потере результатов после reload через UI.
