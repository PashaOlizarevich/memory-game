# Игра, таймер и рейтинг

Источники: [ТЗ](../../docs/TermsOfReference.md), [контракты](../../docs/Architecture.md).

- Стартовая партия: 16 уникальных ID, 8 pairId по два экземпляра; выбранные режимы содержат 16/24/32/40 карточек (8/12/16/20 пар); перемешивается копия алгоритмом Фишера — Йейтса. Закрытое поле, нулевые ходы/пары.
- Ход — вторая другая доступная карточка независимо от изображения. Повторный ID, открытая/найденная карточка, третья при ожидании и выбор после победы игнорируются.
- Engine — источник состояния; фазы idle/one-open/waiting-mismatch/finished, статусы closed/open/matched. Чистые переходы не обращаются к DOM/storage/времени и не меняют вход; snapshots не дают UI изменять engine.
- Mismatch сразу блокирует выбор, один таймер 1000 мс (таск допускает 700–1500). Restart отменяет таймер, меняет roundId и обнуляет состояние; callback проверяет раунд/фазу. Destroy инвалидирует callbacks.
- Рейтинг не сбрасывает/не приостанавливает игру: таймер закрывает пару под окном в исходный срок. Header доступен при ожидании, пока modal закрыт.
- После matchedPairs === totalPairs completedAt фиксируется один раз. Main помечает handledRoundId до addResult/победы. Окна/restart не добавляют результат повторно, включая сбой записи.
- memory-game.leaderboard.v2: { version: 2, results: { easy, medium, hard, expert } }, каждый раздел — массив { difficultyId, moves, completedAt }. Проверяй уровень/раздел и безопасные целые: moves >= числа пар уровня, timestamp >= 0 и допустим для Date. Только при отсутствии v2 переносится валидный v1-массив в easy без удаления v1; повреждённый существующий v2 не запускает импорт.
- Сортировка moves, затем completedAt по возрастанию, при равенстве порядок добавления. Топ-10 отдельно по уровню; одинаковые показатели разных партий допустимы. Место индекс + 1, дата ДД.ММ.ГГГГ в timezone браузера; поле не сохраняется.
- Обрабатывай даже отказ доступа к window.localStorage. При ошибке чтения/записи четыре рейтинга сеанса сохраняется в режиме memory; новые результаты не заменяются старым storage при просмотре. UI получает режим сохранения.
