# Проверки и сдача

Источники: [приёмка](../../docs/TermsOfReference.md), [Architecture](../../docs/Architecture.md), [AGENTS](../../AGENTS.md).

- Проверки по изменениям: документация — ссылки/кодировка/согласованность, без тестов игры. Не устанавливай отсутствующие инструменты без разрешения.
- Код — body только script, относительные импорты/ресурсы, отсутствие запрещённых операций. Упоминания запретов в документации не являются нарушениями кода. Node --check проверяет синтаксис, DOM/поведение — браузер.
- Game: выбор/ходы, match/mismatch/1000 мс, быстрые клики/третья, restart во время таймера/старый callback, победа/одна запись результата.
- Оба окна: три способа закрытия, содержимое, фон/скролл/focus/Tab. Рейтинг при одной карте/mismatch сохраняет игру; таймер не приостанавливается и не сбивает focus окна.
- Storage: равные moves/timestamps, 11 → топ-10, reload на том же origin, некорректные данные, отказ доступа/записи с сохранением списка сеанса. Не очищай чужие ключи ради тестов.
- UI: 320/375/768/1440, keyboard, скрытые имена, fallback, contrast/reduced motion, console/ресурсы. Не объявляй WCAG соответствие без проверки.
- Применяй доступные тесты для инвариантов/гонок; не выдумывай npm scripts и пройденные проверки. Не делай тесты, повторяющие реализацию.
- Перед итогом Git diff/status при наличии Git, область файлов, отсутствие секретов/временных файлов. Непроведённые проверки укажи с причиной.
- Сдача справочно: публичный memory-game, ветка memory-game, деплой, PR «Memory Game» в main с полной самооценкой, в RS App ссылка PR. Не закрывать/мержить до конца проверки. Сроки уточняются в расписании. Git/PR/install/publish — только при действующем явном разрешении пользователя.
