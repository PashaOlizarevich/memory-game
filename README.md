# Memory Game

Учебная игра на поиск пар по [заданию RS School](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md), оформленная в стиле Star Wars. Реализована на HTML, CSS и JavaScript без фреймворков.

## Возможности

- Поле из 16 карточек: найдите все 8 пар за наименьшее число ходов.
- Один ход — открытие двух разных доступных карточек. Совпавшая пара остаётся открытой, несовпавшая закрывается через 1 секунду.
- Счётчики ходов и найденных пар, окно победы и перезапуск игры без перезагрузки страницы.
- Таблица 10 лучших результатов с количеством ходов и датой. Результаты сохраняются в `localStorage`; если оно недоступно, используются только в текущем сеансе.
- Адаптивный интерфейс и управление с клавиатуры.

## Локальный запуск

Сборка и установка зависимостей не требуются. Нужны современный браузер и статический HTTP-сервер. Выберите один из двух способов ниже.

### Через VS Code и Live Server

Для этого способа нужен VS Code и расширение [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) от Ritwick Dey (`ritwickdey.LiveServer`). Другие расширения и Python для запуска не нужны.

1. В VS Code выберите **File → Open Folder…** и откройте папку `memory-game`, в которой находится `index.html`.
2. Откройте раздел **Extensions** сочетанием `Ctrl+Shift+X`, найдите **Live Server** от **Ritwick Dey** и нажмите **Install**. Если расширение уже установлено, пропустите этот шаг.
3. В проводнике VS Code нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**. Также можно открыть `index.html` и нажать **Go Live** в нижней панели VS Code.
4. Игра откроется в браузере по локальному HTTP-адресу. Используйте адрес, который открыл сервер: порт может зависеть от настроек и доступности.
5. После сохранения изменений Live Server автоматически обновляет страницу. Чтобы остановить сервер, откройте палитру команд (`Ctrl+Shift+P`) и выполните **Live Server: Stop Live Server**.

### Через Python и терминал

Для этого способа нужен установленный Python 3. Расширения VS Code не требуются; можно использовать PowerShell или встроенный терминал VS Code (**Terminal → New Terminal**).

1. Перейдите в папку `memory-game`. Если терминал открыт в родительской папке `rsschool`, выполните `cd .\memory-game`. Если уже находитесь в `memory-game`, переходить повторно не нужно.
2. Запустите HTTP-сервер:

   ```powershell
   python -m http.server 8080
   ```

3. Откройте [http://localhost:8080](http://localhost:8080) в браузере. Оставьте терминал с сервером работающим, пока пользуетесь игрой.
4. Чтобы остановить сервер, нажмите `Ctrl+C` в этом терминале.

В Windows, если команда `python` не найдена, но установлен Python Launcher, используйте `py -3 -m http.server 8080`. Если порт 8080 занят, выберите другой, например `python -m http.server 8081`, и откройте `http://localhost:8081`.

Можно использовать другой статический HTTP-сервер из папки проекта. Открытие `index.html` через `file://` не подходит для нативных ES modules.

Результаты в `localStorage` привязаны к адресу сайта, включая порт: при смене `localhost` на `127.0.0.1` или переходе между серверами таблица лидеров может быть другой.
