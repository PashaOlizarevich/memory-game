# Memory Game

Учебная игра на поиск пар по [заданию RS School](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md).

## Текущий статус

Создана структура проекта, подготовлены восемь лицевых изображений карточек и общая рубашка. Реализованы чистые переходы состояния: выбор карточек, подсчёт ходов, совпадение и закрытие несовпавших пар, завершение после восьмой пары. Движок с таймером, интерфейс и рейтинг пока не реализованы. При открытии страницы отображается пустой экран — это ожидаемое поведение основы проекта.

## Стек

- HTML5 и CSS3.
- JavaScript без фреймворков, нативные ES modules.
- DOM API для интерфейса, `localStorage` для будущего рейтинга.
- Нет внешних зависимостей, сборщика или настроенного пакетного менеджера.
- Линтер и форматтер пока не настроены. Регрессионные тесты состояния используют встроенный `node:test`, без внешних зависимостей.

## Локальный запуск

Откройте папку `memory-game` в IDE и используйте уже имеющийся статический HTTP-сервер. Устанавливать зависимости для этой основы не требуется.

Если Python установлен, можно запустить сервер из папки проекта:

```powershell
python -m http.server 8080
```

Затем откройте [http://localhost:8080](http://localhost:8080). Сервер останавливается сочетанием `Ctrl+C`. Для ES modules используйте HTTP-сервер, а не открытие HTML через `file://`.

## Проверки

Регрессионные тесты состояния проверены на Node.js v24.14.1. Запуск всех тестов из папки проекта:

```powershell
node --test tests/*.test.mjs
```

Проверяются повторные клики, найденные пары, блокировка при несовпадении, возобновление выбора после закрытия пары, неизвестные ID и неизменность состояния. Полное прохождение восьми пар проверяет итоговые счётчики, переход в `finished` только после последней пары и однократную фиксацию переданного времени завершения. После завершения выбор карточек и закрытие несовпадения не меняют результат.

При доступном Node.js синтаксис точки входа можно проверить командой:

```powershell
node --check src/main.js
```

Основные правила реализации и будущие сценарии ручной проверки описаны в [AGENTS.md](./AGENTS.md).

## Изображения карточек

В `public/assets/images/cards/` подготовлены восемь оригинальных векторных иллюстраций по [DESIGN](./docs/DESIGN.md):

| Файл | Образ |
| --- | --- |
| `astromech.svg` | Купольный астродроид |
| `protocol-droid.svg` | Протокольный дроид |
| `trooper-helmet.svg` | Белый шлем солдата |
| `dark-helmet.svg` | Тёмный шлем |
| `lightsaber.svg` | Световой меч |
| `starfighter.svg` | Крылатый истребитель |
| `freighter.svg` | Круглый грузовой корабль |
| `space-station.svg` | Космическая станция |

Общая рубашка — `card-back.svg`: симметричная абстрактная эмблема звезды на тёмной стальной панели в палитре DESIGN. Один файл предназначен для всех 16 карточек; при подключении его изображение, ориентация, цвет и рамка должны оставаться одинаковыми независимо от пары. Рубашка не содержит обозначений лицевых образов.

Источник и автор исполнения: созданы Codex непосредственно для этого учебного проекта, без скачивания или копирования сторонних файлов. Это самостоятельные стилизованные рисунки по мотивам Star Wars, не официальные материалы Lucasfilm.

Условия использования: ресурсы подготовлены для учебного Memory Game и включены в его исходники. Заимствованных файлов с отдельными условиями лицензирования нет. Отдельная лицензия на эти SVG в репозитории не установлена.

Все SVG имеют прозрачный фон вне силуэтов, размеры и `viewBox` 256 × 256 и единый стиль; лицевые образы различимы по форме, а рубашка содержит непрозрачную панель. В них нет шрифтов, скриптов, анимации или внешних ресурсов. При подключении используйте относительные пути `./public/assets/images/cards/<имя>.svg` и `object-fit: contain`; путь рубашки — `./public/assets/images/cards/card-back.svg`. Подключение изображений к игре относится к следующим пунктам плана.
