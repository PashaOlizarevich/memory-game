# Memory Game

Учебная игра на поиск пар по [заданию RS School](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md).

## Текущий статус

Создана структура проекта и подготовлены восемь лицевых изображений карточек. Интерфейс, игровая логика, общая рубашка и рейтинг пока не реализованы. При открытии страницы отображается пустой экран — это ожидаемое поведение основы проекта.

## Стек

- HTML5 и CSS3.
- JavaScript без фреймворков, нативные ES modules.
- DOM API для интерфейса, `localStorage` для будущего рейтинга.
- Нет внешних зависимостей, сборщика или настроенного пакетного менеджера.
- Линтер, форматтер и автоматические тесты пока не настроены.

## Структура

```text
memory-game/
├── AGENTS.md                   # Правила проекта для AI-ассистентов
├── README.md                   # Описание и запуск
├── .gitignore
├── index.html                  # Подключение CSS и точки входа
├── src/
│   ├── main.js                 # Запуск приложения и соединение модулей
│   ├── styles/
│   │   └── style.css
│   ├── game/                   # Состояние и правила игры
│   ├── ui/                     # DOM, карточки, счётчики и общая модалка
│   ├── storage/                # Чтение и сохранение рейтинга
│   └── utils/                  # Общие небольшие функции
└── public/
    └── assets/
        └── images/
            └── cards/          # Изображения карточек и рубашки
```

Пустые каталоги содержат `.gitkeep`, чтобы сохраняться в Git. Каталог `public` используется как обычная папка статического сайта: пути к изображениям будут начинаться с `./public/assets/images/`.

## Локальный запуск

Откройте папку `memory-game` в IDE и используйте уже имеющийся статический HTTP-сервер. Устанавливать зависимости для этой основы не требуется.

Если Python установлен, можно запустить сервер из папки проекта:

```powershell
python -m http.server 8080
```

Затем откройте [http://localhost:8080](http://localhost:8080). Сервер останавливается сочетанием `Ctrl+C`. Для ES modules используйте HTTP-сервер, а не открытие HTML через `file://`.

## Проверки

Автоматических тестов пока нет. При доступном Node.js синтаксис точки входа можно проверить командой:

```powershell
node --check src/main.js
```

Основные правила реализации и будущие сценарии ручной проверки описаны в [AGENTS.md](./AGENTS.md).

## Изображения карточек

В `public/assets/images/cards/` подготовлены восемь оригинальных векторных иллюстраций по [DESIGN](./docs/DESIGN.md):

| Файл | Образ |
| --- | --- |
| `astromech.svg` | Купольный астродроид |
| `protocol-droid.svg` | Протокольный дроид |
| `trooper-helmet.svg` | Белый шлем солдата |
| `dark-helmet.svg` | Тёмный шлем |
| `lightsaber.svg` | Световой меч |
| `starfighter.svg` | Крылатый истребитель |
| `freighter.svg` | Круглый грузовой корабль |
| `space-station.svg` | Космическая станция |

Источник и автор исполнения: созданы Codex непосредственно для этого учебного проекта, без скачивания или копирования сторонних файлов. Это самостоятельные стилизованные рисунки по мотивам Star Wars, не официальные материалы Lucasfilm.

Все SVG имеют прозрачный фон, размеры и `viewBox` 256 × 256, единый стиль и различимые силуэты. В них нет шрифтов, скриптов, анимации или внешних ресурсов. При подключении используйте относительные пути `./public/assets/images/cards/<имя>.svg` и `object-fit: contain`. Подключение изображений к игре и общая рубашка относятся к следующим пунктам плана.
