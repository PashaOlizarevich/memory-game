## Среда и воспроизведение

Windows, Node.js v24.14.1, Chrome 154.0.8037.97 headless. Нативные ES modules, внешних зависимостей и сборщика нет. Использованы статический HTTP-сервер на 127.0.0.1 и Chrome DevTools Protocol через встроенный WebSocket Node.js. Browser plugin и проектный Playwright отсутствуют; зависимости не устанавливались. Вспомогательные скрипты, профили и снимки находятся во временном каталоге вне репозитория.

Команды из корня проекта:

```powershell
node --test tests/*.test.mjs
$sourceFiles = @(rg --files src tests -g '*.js' -g '*.mjs')
foreach ($sourceFile in $sourceFiles) {
    node --check $sourceFile
    if ($LASTEXITCODE -ne 0) { throw $sourceFile }
}
git diff --check
```

## Результаты по пунктам

| Пункт | Проверка и фактический результат |
| --- | --- |
| 36 | Обе кнопки вызывают общий `startNewGame`: закрытие окна, затем синхронный restart. Одна активация создаёт ровно следующий roundId, новую колоду и нулевые счётчики. Старый таймер отменяется; рейтинг, исходный overflow с приоритетами и фокус сохраняются/восстанавливаются. Повторный цикл не создаёт лишних обработчиков. |
| 37 | Добавлены два регрессионных сценария. Рейтинг при одной карте сохраняет все DOM-узлы, статусы, имена и счётчики; после закрытия можно закончить ту же пару. При несовпадении реальный таймер продолжает работать примерно 1000 мс за окном. Счётчики и найденная пара сохраняются, содержимое окна и его DOM-узлы не меняются, фокус остаётся на действии окна. |
| 38 | В отдельном профиле загружены 12 записей, включая равные ходы с разными timestamp. Проверены порядок moves/completedAt и десять лучших в данных и таблице. Победа сохраняет топ-10; повторное открытие окна не изменяет сериализованные записи. Перезагрузка сохраняет результат. Chrome полностью закрыт и вновь запущен с тем же профилем и HTTP-origin: тот же рейтинг и десять строк восстановлены. Посторонний ключ сохранён. |
| 39 | Проверены повреждённый JSON, объект вместо массива, смесь корректных и некорректных записей, SecurityError getter localStorage, отказ getItem и QuotaExceededError setItem. В каждом случае настоящая страница позволяет завершить две партии и начать новую. Повторный рейтинг показывает актуальные результаты; некорректные записи исключены. При недоступном storage оба окна показывают сообщение DESIGN, список сохраняется в памяти без повторных обращений. Посторонний ключ не меняется. |
| 40 | Настоящий браузерный ввод Tab/Shift+Tab/Enter/Space/Escape подтвердил переход между кнопками, открытие рейтинга, циклический фокус окна, возврат к триггеру, выбор карточки и restart. Закрытые изображения используют общую рубашку, пустой alt и скрытый/пустой fallback; имя не содержит образа. Игра, победа и рейтинг из десяти строк проверены измерениями и просмотром снимков на 320, 375, 768, 1440 px: квадратные карты, отсутствие горизонтальной прокрутки и обрезания содержимого окон. Reduced motion отключает transition/animation и сохраняет игровой таймер. |
| 41 | Субагент проверил исходники: body index.html содержит только script, UI создаётся createElement/textContent и DOM-методами; запрещённых операций и сторонних игровых библиотек нет. Все импорты относительные. Настоящая страница загружена также под `/memory-game/index.html`: CSS, модули и все девять SVG доступны. Console/Runtime и Network не выявили ошибок приложения или отказов ресурсов. |

В проверке ресурсов тестовый сервер возвращает 204 для необязательного favicon. Ошибки загрузки, намеренно создаваемые тестами image fallback, относятся к этим тестам; чистота Console/Network проверена отдельно на настоящей странице.

Снимки подтверждают видимый контур клавиатурного фокуса и различимые найденные пары.
