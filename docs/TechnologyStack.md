# Технологический стек Memory Game

> Статус на 13.10.2026: реализованы уровни 16/24/32/40, двадцать анимированных образов и отдельные рейтинги v2. При открытии запускается базовый режим RS School на 16 карточек. Итоговая локальная приёмка: [87 Node-тестов и 70 браузерных сценариев](./DifficultyAcceptanceValidation.md). Деплой, другие браузеры, реальные устройства и скринридер не проверены.

Документ описывает самостоятельный проект `memory-game`. Основание — [официальное задание RS School](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md), проверенное 5 октября 2026 года, и фактические файлы проекта. Правила разработки находятся в [AGENTS.md](../AGENTS.md), инструкция запуска — в [README.md](../README.md).

## Что настроено сейчас

| Технология | Назначение и текущее состояние |
| --- | --- |
| HTML | `index.html`: метаданные, подключение CSS и скрипта. В исходном `<body>` только `<script>`. |
| CSS | В `src/styles/style.css` реализованы тема, состояния, адаптивность и reduced motion. |
| JavaScript без фреймворков | `src/main.js` соединяет движок, экран, модальное окно и хранилище. |
| Нативные ES modules | Скрипт подключён с `type="module"`; модули используют относительные импорты с расширением `.js`. |
| Статические ресурсы | В `public/assets/images/cards/` находятся двадцать анимированных SVG-образов и общая рубашка. |
| Фоновая музыка | Пользовательский MP3 в `public/assets/audio/`; нативный HTMLMediaElement управляет повтором, громкостью и паузой без сторонних библиотек. |

При загрузке автоматически начинается партия: 16 закрытых карточек, восемь пар, нулевые счётчики. Реализованы четыре уровня, оба окна и отдельные рейтинги с резервным хранением в памяти.

Внешних зависимостей, `package.json`, lock-файлов и сборщика нет. Пакетный менеджер не выбран. Линтер и форматтер не настроены. Тесты используют встроенный node:test и браузерные страницы `tests/*.browser.html`. Серверная часть и база данных отсутствуют.

HTML и CSS используются как браузерные стандарты, а не пакеты с зафиксированными версиями. Конкретная версия ECMAScript и минимальные версии браузеров в проекте пока не закреплены; для запуска нужен современный браузер с ES modules, DOM API и inert. Последняя проверенная среда: Node.js v24.14.1 и Chrome 155.0.0.0 (navigator.userAgent); это не минимальная версия.

## API реализации

Реализация использует встроенные возможности браузера и JavaScript без сторонних библиотек.

| API | Применение | Документация |
| --- | --- | --- |
| `document.createElement` | Создание всех элементов интерфейса | [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Document/createElement) |
| `Element.append` | Добавление элементов в DOM | [MDN](https://developer.mozilla.org/ru/docs/Web/API/Element/append) |
| `textContent` | Вывод текстов и счётчиков | [MDN](https://developer.mozilla.org/ru/docs/Web/API/Node/textContent) |
| `dataset`, `className` | Статусы и оформление элементов | [MDN](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/dataset) |
| `addEventListener` | Обработка кликов и клавиатуры | [MDN](https://developer.mozilla.org/ru/docs/Web/API/EventTarget/addEventListener) |
| `KeyboardEvent.key` | Обработка Escape | [MDN](https://developer.mozilla.org/ru/docs/Web/API/KeyboardEvent/key) |
| `setTimeout`, `clearTimeout` | Отложенное закрытие пары и отмена таймера | [setTimeout](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout), [clearTimeout](https://developer.mozilla.org/en-US/docs/Web/API/Window/clearTimeout) |
| `Array` | Коллекции карточек и результатов | [MDN](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/Array) |
| `Math.random` | Получение случайных значений для перемешивания | [MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random) |
| `localStorage` | Сохранение рейтинга между посещениями | [MDN](https://developer.mozilla.org/ru/docs/Web/API/Window/localStorage) |
| `JSON.stringify`, `JSON.parse` | Преобразование результатов в строку и обратно | [MDN](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/JSON) |
| `Date` | Дата результата и время для сортировки | [MDN](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/Date) |

Ссылки MDN, кроме дополнительной ссылки на `Math.random`, приведены в разделе материалов задания. Реализован алгоритм Фишера — Йейтса в `src/game/shuffle.js`.

`localStorage` хранит строковые значения и относится к origin страницы: смена протокола, хоста или порта означает другое хранилище. Хранилище проверяет данные, обрабатывает повреждённый JSON и ошибки доступа, чтения и записи; при недоступном storage использует память сеанса.

Общая модальная оболочка реализована на DOM в `src/ui/modal.js`, с inert, управлением фокусом и прокруткой. [Fetch API](https://developer.mozilla.org/ru/docs/Web/API/Fetch_API/Using_Fetch) допускается для отдельного файла данных карточек, но пока не используется.

## Требования задания, влияющие на реализацию

- Поле содержит 16 карточек — 8 пар. Случайное перемешивание выполняется при загрузке и новой игре.
- Ход считается при открытии второй другой доступной карточки независимо от совпадения изображений. Повторные клики игнорируются.
- Несовпавшая пара закрывается через 700–1500 мс; до этого выбор других карточек блокируется. Перезапуск отменяет таймер, просмотр рейтинга — нет.
- Победа и рейтинг используют общую оболочку модального окна. Закрытие: кнопка, фон, Escape; фон и прокрутка блокируются.
- Рейтинг сохраняет один результат после победы и оставляет 10 лучших: меньше ходов выше, при равенстве раньше завершённая игра выше. Дата отображается как `ДД.ММ.ГГГГ`.
- Весь интерфейс создаётся через `document.createElement`, включая модальные окна. Самописные обёртки разрешены.
- Запрещены присваивания `innerHTML`/`outerHTML`, `insertAdjacentHTML`, `document.write`/`writeln`, разбор HTML через `DOMParser`/`Range.createContextualFragment`, `alert`/`confirm`/`prompt` и сторонние библиотеки интерфейса, DOM и игровой логики.

Источник требований — [раздел «Требования к реализации»](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md#требования-к-реализации). Дизайн свободный; конкретная сетка, звук и анимации не определяют выбранный стек.

## Организация проекта

| Путь | Ответственность |
| --- | --- |
| `index.html` | Подключение стилей и точки входа |
| `src/main.js` | Запуск приложения и соединение модулей |
| `src/game/` | Состояние, перемешивание, ходы, совпадения и таймеры; без DOM и хранения |
| `src/ui/` | Создание DOM, события, отображение состояния и общая модальная оболочка |
| `src/storage/` | Чтение, проверка, сортировка и сохранение результатов |
| `src/utils/` | Общие небольшие функции по мере необходимости |
| `src/styles/style.css` | Оформление приложения |
| `public/assets/images/cards/` | Изображения карточек и рубашки |
| `docs/` | Документация проекта, включая этот файл |

Каталоги содержат рабочие модули и SVG-ресурсы. Импорты используют относительные пути с расширением `.js`. Без сборщика `public` остаётся обычным каталогом: путь к изображениям начинается с `./public/assets/images/`.

## Запуск и проверка

Приложение исполняется в браузере. Сборка и установка зависимостей не требуются. Используйте имеющийся статический HTTP-сервер из каталога `memory-game`; открытие через `file://` не подходит для работы ES modules.

Например, если Python уже установлен:

```powershell
python -m http.server 8080
```

Откройте [http://localhost:8080](http://localhost:8080); остановка сервера — `Ctrl+C`. Python здесь лишь необязательный способ раздачи файлов, а не часть стека приложения.

Если Node.js уже установлен, из каталога проекта можно проверить синтаксис точки входа:

```powershell
node --check src/main.js
```

Node.js — вспомогательный инструмент проверки, не среда исполнения игры. Проверки выполнены на Node.js v24.14.1; версия не закреплена конфигурацией проекта. Регрессионные тесты запускаются командой `node --test tests/*.test.mjs`. Эта команда не проверяет DOM и игровое поведение.

В локальной приёмке выполнены браузерные проверки: быстрые клики, несовпавшая пара, перезапуск во время таймера, победа, закрытие модальных окон и сохранение рейтинга после перезагрузки. Проверять ошибки загрузки и JavaScript следует в инструментах разработчика браузера.

Сборщики, линтеры, форматтеры и тестовые инструменты [разрешены заданием](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md#интерфейс-и-инструменты), но внешние инструменты не установлены; используется встроенный node:test. Актуальные результаты: [DifficultyAcceptanceValidation](./DifficultyAcceptanceValidation.md), 87 Node-тестов и 70 браузерных сценариев. Исторический AcceptanceValidation сохраняет результаты исходной игры. Проверка публичного деплоя остаётся для пункта 45 плана. Их добавление требует согласования согласно правилам проекта.

## Реализованное расширение без смены стека

Уровни 16/24/32/40 карточек, каталог из 20 анимированных образов и рейтинги v2 реализованы. src/game/difficulty.js задаёт конфигурации, src/game/cards.js формирует вложенные наборы 8/12/16/20 образов. Состояние вычисляет totalPairs, движок принимает restart({ pairIds }), main хранит activeDifficultyId отдельно от выбора UI. HTML/CSS/vanilla JavaScript, ES modules, SVG и localStorage сохраняются; новые зависимости не добавлены. При отсутствии v2 валидные v1-результаты переносятся в easy без удаления старого ключа. Контракты — в [Architecture](./Architecture.md#10-реализованная-архитектура-уровней-сложности), результаты — в [приёмке](./DifficultyAcceptanceValidation.md).
