# План реализации Memory Game

Выполнять пункты последовательно по [ТЗ](./TermsOfReference.md), [архитектуре](./Architecture.md), [дизайну](./DESIGN.md) и [правилам проекта](../AGENTS.md). Список описывает будущую работу. Git-операции и публикацию выполнять при наличии разрешения пользователя.

1. **Выполнено:** подготовлены восемь различимых оригинальных SVG-изображений в стиле «Звёздных войн» по DESIGN; файлы находятся в `public/assets/images/cards/`, описание ресурсов — в README.
2. **Выполнено:** подготовлена единая рубашка `public/assets/images/cards/card-back.svg` — симметричная абстрактная эмблема звезды на стальной панели по DESIGN; она предназначена для всех карточек независимо от пары.
3. Сохранить изображения в `public/assets/images/cards/` и указать источники и условия использования в README при необходимости.
4. Создать `src/game/cards.js` с данными восьми образов `{ pairId, label, imageUrl }` и путём рубашки.
5. Создать `src/game/shuffle.js` и реализовать перемешивание копии массива алгоритмом Фишера — Йейтса.
6. Создать `src/game/state.js` и реализовать начальную колоду: 16 уникальных карточек, восемь пар, закрытые стороны, нулевые счётчики.
7. Реализовать в `state.js` выбор первой карточки без увеличения числа ходов.
8. Реализовать выбор второй другой доступной карточки с увеличением числа ходов на один независимо от совпадения.
9. Реализовать сравнение по `pairId`: найденную пару оставлять открытой и увеличивать число пар на один.
10. Реализовать переход несовпавшей пары в состояние ожидания и её последующее закрытие.
11. Реализовать игнорирование повторных кликов, найденных пар, третьей карточки при ожидании и выбора после завершения игры.
12. Реализовать завершение партии после нахождения восьмой пары.
13. Создать `src/game/engine.js` с методами `restart`, `choose`, `getSnapshot` и `destroy` по Architecture.
14. Реализовать хранение актуального состояния в движке и передачу независимых снимков интерфейсу через уведомления.
15. Реализовать один таймер закрытия несовпавшей пары на 1000 мс и немедленную блокировку выбора до его завершения.
16. Реализовать перезапуск с отменой таймера, сменой `roundId`, перемешиванием поля и обнулением счётчиков.
17. Реализовать защиту новой партии от устаревших callbacks и освобождение таймера при `destroy`.
18. Проверить игровые переходы, счётчики и перезапуск во время таймера до подключения интерфейса доступными средствами.
19. Создать `src/ui/app-view.js` и сформировать через `document.createElement` хедер, кнопки, счётчики, инструкцию и поле из 16 карточек.
20. Реализовать `render(snapshot)` и callbacks действий; обновлять поле без пересоздания главного экрана, новую колоду создавать при смене раунда.
21. Подключить движок и главный экран в `src/main.js` для автоматического старта, выбора карточек и перезапуска.
22. Реализовать доступные имена карточек и скрытие закрытых образов; показывать текстовую замену ошибочного изображения только после открытия.
23. Добавить в `src/styles/style.css` цвета, шрифты, отступы и радиусы из DESIGN.
24. Оформить космический фон, хедер, кнопки, счётчики и игровую сетку 4 × 4.
25. Оформить состояния карточек: закрытая, открытая, найденная, hover и focus-visible.
26. Реализовать адаптивность от 320 px без горизонтальной прокрутки и поддержку `prefers-reduced-motion`.
27. Создать `src/ui/modal.js` с одной общей DOM-оболочкой для победы и рейтинга.
28. Реализовать закрытие модалки кнопкой, кликом по фону и Escape; клики по содержимому не должны закрывать окно.
29. Реализовать блокировку фона и прокрутки, перевод и удержание фокуса в модалке и восстановление после закрытия.
30. Создать `src/ui/modal-content.js` с содержимым победы, таблицей лидеров и пустым состоянием рейтинга; оформить окна по DESIGN.
31. Создать `src/utils/format-date.js` для вывода даты `ДД.ММ.ГГГГ` в часовом поясе браузера.
32. Создать `src/storage/leaderboard.js` для чтения и записи результатов `{ moves, completedAt }` по ключу `memory-game.leaderboard.v1`.
33. Реализовать проверку данных, сортировку по ходам и времени завершения и ограничение рейтинга десятью лучшими результатами.
