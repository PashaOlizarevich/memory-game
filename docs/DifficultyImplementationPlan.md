# План реализации уровней сложности Memory Game

Статус: пункт 1 выполнен и проверен; остальные пункты расширения ещё не реализованы.

Пункты пронумерованы сквозным списком. Отмечать `[x]` только после выполнения и проверки соответствующей задачи.

Цель: добавить уровни на 16, 24, 32 и 40 карточек, расширить каталог до 20 образов и разделить рейтинги. Сохраняем HTML, CSS и vanilla JavaScript с нативными ES modules, без новых зависимостей.

В текущем коде победа наступает строго после 8 пар, движок закрепляет набор карточек при создании, рейтинг общий и допускает результаты от 8 ходов. Эти ограничения нужно адаптировать.

## 1. Уровни и правила

| Уровень | Карточки | Пары | Сетка на широком экране |
| --- | ---: | ---: | --- |
| Лёгкий | 16 | 8 | 4 × 4 |
| Средний | 24 | 12 | 6 × 4 |
| Сложный | 32 | 16 | 8 × 4 |
| Эксперт | 40 | 20 | 8 × 5 |

- [ ] 2. Выбор другого уровня применяется кнопкой «Начать игру». До её нажатия текущая партия продолжается.
- [ ] 3. «Новая игра» повторяет текущий уровень.
- [ ] 4. Несовпавшая пара закрывается через 1 секунду на всех уровнях.
- [ ] 5. Состав каждого уровня фиксирован, расположение карточек случайное.
- [ ] 6. Таймер и дополнительные игровые правила пока не добавляем.

## 2. Каталог из 20 образов

Сохраняем восемь существующих изображений и добавляем двенадцать персонажей. Каждый следующий уровень включает набор предыдущего.

| Уровень | Добавляемые персонажи |
| --- | --- |
| Средний | Йода, Чубакка, Лея, Дарт Мол |
| Сложный | Люк, Хан Соло, Боба Фетт, Асока |
| Эксперт | Оби-Ван, Палпатин, Гривус, Джава |

Сначала создаём статичные SVG в стиле нынешних карточек. Проверяем различимость персонажей на маленьком экране, затем добавляем спокойные анимации открытия и найденной пары. Учитываем настройку уменьшения движения.

Файлы: `src/game/cards.js`, новые SVG в `public/assets/images/cards/`.
