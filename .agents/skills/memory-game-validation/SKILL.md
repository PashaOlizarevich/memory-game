# Проверка Memory Game

Прочитай [AGENTS](../../../AGENTS.md), [правила проверок](../../../.codex/rules/testing-and-delivery.md), затронутые критерии [ТЗ](../../../docs/TermsOfReference.md)/[Architecture](../../../docs/Architecture.md). Для визуала — [DESIGN](../../../docs/DESIGN.md), запуска — [README](../../../README.md).

## Workflow

1. Определи реальные изменения/статус. Тестовый инструмент/линтер не настроены; не выдумывай команды, доступный MCP или результаты. Документация — ссылки/кодировка/согласованность без запуска игры.
2. Код: подключения/body только script, UI createElement/textContent. Отличай запрещённые операции в коде от упоминаний в документах: запись innerHTML/outerHTML, insertAdjacentHTML, document.write/writeln, DOMParser/Range.createContextualFragment для HTML, alert/confirm/prompt, UI/DOM/игровые библиотеки. Node синтаксис не доказывает DOM.
3. Выбери сценарии по изменению: 16/8, второй выбор +1 ход, match/mismatch, быстрые клики/третья, 1000 мс, restart/старый callback, finished. Таймер в фоновой вкладке может задерживаться.
4. UI: оба окна/общая оболочка, кнопка/фон/Escape/содержимое, background/scroll/focus/Tab. Рейтинг при одной карте/mismatch сохраняет игру/таймер; callback не сбивает окно. Keyboard/скрытые имена/fallback/reduced motion, 320/375/768/1440, console/ресурсы.
5. Storage: одна запись за roundId, даже при отказе записи; равные moves/timestamps, 11 → 10, дата/место, reload на одном origin. Неверные данные/отказ доступа не ломают игру; память сохраняет новые результаты при повторном рейтинге. Не удаляй чужие данные для тестов.
6. Доступные тесты — переходы/нормализация/таймер; браузер — focus/layout/интеграция. Не дублируй реализацию тестами и не устанавливай инструменты без разрешения. Для проблемы сообщи воспроизведение/причину, исправляй в рамках запроса.
7. Git diff/status при наличии Git, относимость файлов/отсутствие секретов/временных файлов. Отчёт разделяет проверенное/непроверенное/нерешённое, даёт пути и рекомендованный коммит. Подготовка сдачи не разрешает commit/push/PR/deploy: требуется явное разрешение пользователя.
